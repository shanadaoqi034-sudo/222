# Changelog

## 1.0.0 — First source release

- Establish a clearly scoped iOS 17.0 / RootHide / ElleKit source release.
- Include Settings > NeoStatus PreferenceBundle and PreferenceLoader entry.
- Include opt-in SpringBoard preview gesture and two-page UIKit visual preview.
- Include local tile layout editing and persistence.
- Include public-framework brightness, volume, media and flashlight actions.

- Include runtime diagnostics with bounded snapshots and restrictive file permissions.
- Improve malformed saved-layout handling and make glass/rounded preferences refresh consistently.
- Configure the RootHide Theos project for the iPhone 15 Pro arm64e target.
- Document native integration boundaries and upstream licensing status.
